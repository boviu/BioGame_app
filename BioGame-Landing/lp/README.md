# BioGame – Landing Page

Site de divulgação do BioGame, jogo educativo de meio ambiente para celular.

## Como rodar
Não precisa instalar nada. Mantenha a pasta `imagens/` ao lado do `index.html` e abra o arquivo em qualquer navegador (ou use a extensão Live Server no VS Code).

## Tecnologias
HTML5, CSS3 (Flexbox, Grid, variáveis e media queries, tema claro/escuro automático) e Google Fonts (Inter).
